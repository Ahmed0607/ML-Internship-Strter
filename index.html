Structured Content Archetype Clustering: Moving Beyond Heuristics

Acknowledgments & Data Credit: Built on the FlyRank ML Internship dataset (FlyRankAI).

1. Abstract

How can editorial teams efficiently prioritize content updates across millions of URLs without relying on arbitrary, rigid rules? Using an anonymized 79-million-row search performance dataset from FlyRank, this project evaluated structural and behavioral metrics to identify actionable content archetypes. I developed an unsupervised K-Means clustering model (k=4) and validated it using a strict 80/20 grouped-client holdout to prevent domain-level leakage. While a naive random split suggested high predictability (Precision@50: 0.700), testing on unseen clients crashed precision to 0.220 (below the 0.440 base rate), revealing that structural SEO metrics heavily overfit to specific domain architectures. This demonstrates that while behavioral clustering is a powerful triage engine within a known domain, cross-domain automated content decisions require semantic context.

2. Introduction / Problem Statement

FlyRank faces a massive scale problem: prioritizing editorial updates across millions of content rows without wasting time on evergreen utility pages. For example, a simple heuristic (e.g., "rewrite if older than 180 days and impressions > 500") might accurately flag a decaying blog post, but it will also flag a stable "Privacy Policy" or "Contact Us" page that naturally gets traffic and age but never needs a rewrite. This project replaces these arbitrary human thresholds with unsupervised machine learning to discover organic, mathematically backed performance patterns, aiming to solve the exact triage bottleneck content teams face daily.

3. Data

This analysis uses the FlyRank/internship-warehouse release (v20260703). The grain is a single pseudonymized content item's aggregated metrics for the mid-panel month of March 2026. I deliberately excluded raw text and product-derived context flags to avoid circular logic and maintain public safety.

4. Methodology

  • Model: K-Means clustering (k=4) applied to scaled numerical features.
  • Validation: An 80/20 Grouped Train/Test Split on client_id was strictly enforced to prevent client-overlap leakage.

5. Results

Evaluated on the 20% strict client-holdout split at K=50:

  • Base Rate (Random Picking): 0.440
  • K-Means Model Precision@50: 0.220
  • Naive Split Precision@50 (The Leakage Trap): 0.700

The model experienced a massive precision collapse when tested on completely unseen clients. Structural clustering successfully identifies decaying pages within a known domain, but struggles to generalize without topical context.

6. Limitations & Honest Framing

This is a directional, decision-support tool, not causal proof of Google's algorithm. A known limitation is our "semantic blind spot." By excluding raw text, the model groups pages that behave similarly but cannot verify if they cover similar intents.
